# UI/UX design loop

Use [SKILL.md](SKILL.md) for orchestration, [rubric.md](rubric.md) for acceptance, and [impeccable-map.md](impeccable-map.md) for the installed Impeccable contract.

The parent collects matching screenshots, audit findings, and live behavior evidence before each independent grade. Raw scores for applicable dimensions determine acceptance; justified N/A dimensions are excluded, while unverified dimensions prevent acceptance. Optional weights only prioritize repairs. The parent owns the default budget of one inspection and one confirmation and reports exhaustion separately from the grader's quality verdict. A completed PASS ends the task without an extra confirmation or polishing pass.

Templates describe only the selected flow and compatibility surfaces. Missing evidence blocks a PASS. No P0/P1 finding may be waived through a visual tradeoff.
